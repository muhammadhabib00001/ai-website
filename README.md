# NexusSphere &mdash; Frontier AI & Technology Editorial Publication

A modern, high-performance, multi-page editorial website and knowledge hub designed for digital publications, technology research labs, and content hubs.

## 🚀 Live Demo & Structure

- **`index.html`**: Homepage featuring hero showcase banner, reader statistics, featured marquee investigation, categories taxonomy, trending articles grid, and newsletter subscription.
- **`article.html`**: Flagship 1,600+ word deep-dive editorial (*"The Definitive Guide to Artificial General Intelligence and the Next Era of Human-Machine Collaboration"*), with dynamic reading progress bar, sticky Table of Contents with active section ScrollSpy, high-resolution figures, architectural comparison table, and FAQ accordion.
- **`categories.html`**: Interactive categories directory with live tag/category filters (*AI & Agents, Smart Cities, Biotech & Health, Economics, Clean Energy*) and instant keyword search.
- **`about.html`**: Editorial mission, core principles, standards, and leadership profiles.
- **`contact.html`**: Interactive contact form with live validation feedback, bureau coordinates, and FAQ accordion.
- **`privacy.html`**: Privacy policy, data governance, and terms of service.

## ✨ Features

- **Dark & Light Mode Toggle**: Instant theme switching with `localStorage` persistence.
- **Ultra-Fast & Zero Dependencies**: Built with vanilla semantic HTML5, modern CSS3 (custom properties, Grid, Flexbox), and modular JavaScript.
- **High-Quality Visuals**: High-resolution editorial photography in `assets/images/`.
- **Fully Responsive**: Mobile-first responsive layouts across mobile, tablet, and desktop viewports.

## 📦 How to Run

Simply open `index.html` in any modern web browser or serve via any static web server:

```bash
# Using Python
python -m http.server 8000

# Using Node.js (npx)
npx serve .
```
